# N3 題庫出題規範

題庫是純靜態 JS。每個檔案放在 `n3-sprint/dist/data/<name>.js`，直接呼叫全域 `Bank`（定義於 `dist/bank.js`）。
**正解永遠寫在第一個選項**，App 會在出題時洗牌。只寫自己被指派的檔案，不要改其他檔案。

## API

```js
// 文字詞彙、文法（一列一題）。prefix 在全題庫必須唯一，題目 id = prefix-01, prefix-02…
Bank.group('kanji-a', '漢字讀音', [
  // [題幹, 正解, 誤答1, 誤答2, 誤答3, 繁中解析]
  ['昼から雨が【激しく】なった。', 'はげしく', 'けわしく', 'くやしく', 'まぶしく', '「激しい（はげしい）」表示劇烈…'],
]);

// 共用文章的題組（讀解四類、文章文法）。id 全題庫唯一。
Bank.passage('rs-umbrella', '短文理解', `文章本文…`, [
  // [提問, 正解, 誤答1, 誤答2, 誤答3, 繁中解析]
  ['美術館が新しい道具を置いた目的は何か。', '…', '…', '…', '…', '解析…'],
]);

// 聽解（一段音檔一題；由瀏覽器語音合成朗讀）。
Bank.listen('lk-01', '課題理解',
  {scene: '会社で男の人と女の人が話しています。', question: '男の人はこのあとまず何をしますか。',
   script: [['F', '田中さん、…'], ['M', 'はい、…']]},
  ['正解', '誤答1', '誤答2', '誤答3'], '繁中解析');

// 佛腳筆記
Bank.addNotes('g-a', 'grammar', [
  // [句型, 接續, 中文意思, 例句, 例句中譯, 易錯提醒(可省略)]
  ['〜うちに', '動詞辞書形／ない形・い形・な形＋な・名詞＋の', '趁著…的時候', '温かいうちに食べてください。', '請趁熱吃。', '與「〜間に」不同…'],
]);
Bank.addNotes('c-a', 'confuse', [
  // [標題, [[詞, 讀音, 中文意思, 例句], …至少兩個], 辨析說明]
  ['預ける／預かる', [['預ける', 'あずける', '寄放（交給別人）', '荷物をホテルに預ける。'], ['預かる', 'あずかる', '代為保管', '荷物をお預かりします。']], '主語是「交出去的人」用預ける…'],
]);
```

## 各題型題幹格式

| 類型 | 題幹 | 選項 |
|---|---|---|
| 漢字讀音 | 句子，目標詞用【】標示，如 `風で看板が【倒れた】。` | 平假名讀音；誤答要是形近、長短音、濁音、促音等真實易混讀法 |
| 文字表記 | 句子，目標詞以平假名寫在【】內 | 漢字寫法；誤答用同音／形近漢字 |
| 文脈選詞 | 句子含一個 `（　）`（全形括號＋全形空白） | 同詞性的四個詞 |
| 近義改寫 | 句子，目標詞用【】 | 意思最接近的說法 |
| 詞語用法 | 題幹只寫目標詞，如 `せっかく` | 四個完整句子，只有一句用法正確；句中的目標詞不加任何標記 |
| 文法形式 | 句子或兩人對話（`Ａ「…」\nＢ「…」`）含一個 `（　）` | 文法形式 |
| 句子排列 | `…＿＿　＿＿　★　＿＿…`（三個＿＿、一個★，★可在四格中任一格；請平均分配★的位置） | 四個片段；**第一個選項是★位置的片段**；解析開頭寫出完整順序 |
| 文章文法 | `Bank.passage`，本文中以 `（ 1 ）`…`（ 5 ）` 標空格，每空一題，提問寫 `（ 1 ）に入る最もよいものはどれか。` | 接續詞、文末表現、指示詞、助詞等 |
| 短文理解 | 150–200 字本文，1 題 | |
| 中篇理解 | 約 350 字本文，3 題 | |
| 長文理解 | 約 550 字本文，4 題 | |
| 資訊檢索 | 約 600 字的公告／傳單／一覽表（用換行、■、・排版），2 題 | |
| 課題理解 | scene＋對話 script＋question（接下來要做什麼） | 4 個文字選項 |
| ポイント理解 | scene＋對話／獨白＋question（原因、時間、哪一個等） | 4 個文字選項 |
| 概要理解 | scene＋獨白或對話＋question（主旨、說話者意圖） | 4 個文字選項 |
| 発話表現 | 只有 scene：情境＋`何と言いますか。`，script 留空 `[]` | **3 個**選項（會被朗讀） |
| 即時応答 | script 只有一句話 `[['M','…']]`，不需 scene／question | **3 個**回應（會被朗讀） |

script 的說話者代號：`M` 男、`F` 女、`M2`／`F2` 第二位男／女、`N` 旁白。

## 品質要求

- 程度鎖定 JLPT N3：N3 核心語彙與文法為主，可混入少量 N4 複習與 N2 入門；文章用字不超出 N3 太多，超出的漢字改寫假名或換詞。
- **只能有一個正解**。誤答必須是「看起來合理、但明確錯誤」，不可出現兩個選項都說得通的情況。寫完每題要反問自己：母語者會不會覺得另一個選項也可以？
- 全部原創，不可抄錄 JLPT 官方題或市售教材的題目與文章。
- 題材分散（生活、學校、職場、旅遊、社區、健康、環境、科技、興趣…），同一檔案內不重複考同一個詞／同一個句型的同一種用法。
- 解析用**繁體中文（台灣用語）**，日文詞句用「」引用。要說明正解為什麼對，並點出最有誘答力的誤答為什麼錯，1–3 句。
- 解析**不可用位置指稱選項**（「第二項」「選項 A」）：App 會洗牌，請直接引用選項內容。
- 讀解主旨題的四個選項要長度、語氣、抽象程度一致，都是同題材下合理的主張；不可讓正解成為唯一溫和／唯一最長的選項（要能通過「不看本文猜題」測試：`node tools/quiz.mjs export <file> --no-passage`）。
- 讀解解析要指出本文中的依據句。
- 日文一律用日本的標準表記（新字體）；不要使用簡體字。
- 聽解文字會交給語音合成：避免罕見人名地名、避免同形異音詞造成誤讀（必要時寫假名）、不要用括號或符號；每句自然口語、長度適中。
- 字串用單引號；本文用反引號。句中若有單引號要跳脫。不要寫任何輔助程式碼，檔案只包含註解與 `Bank.*` 呼叫。

## 檢查

在 `n3-sprint/` 目錄下執行：

```sh
node tools/validate.mjs data/<name>.js   # 只列出該檔的問題；必須顯示 OK
```

新檔案寫好後跑一次 `node tools/manifest.mjs`，App 才會知道它（不帶參數的 `validate.mjs` 會檢查索引是否最新）。交件前請自己重讀全部題目一遍，逐題確認唯一正解與日文自然度。
