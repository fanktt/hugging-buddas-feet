# 假名注音（ふりがな）標註規範

`dist/ruby/<檔名>.js` 是題庫文字的副本，要在其中的漢字上標註讀音，寫法是 `{漢字|かんじ}`。網站會把它顯示成漢字上方的假名。
**除了加上 `{…|…}` 以外，一個字、一個標點、一個空白都不能改**；檢查程式會把標記去掉後與原文逐字比對。

## 寫法

- 以「詞」為單位標註，送假名留在外面：`{食|た}べる`、`{取|と}り{消|け}す`、`{引|ひ}き{受|う}ける`、`{予約|よやく}`、`{日本語|にほんご}`、`お{金|かね}`、`{気|き}をつける`。
- 熟字訓與不可分的讀法整個詞一起標：`{今日|きょう}`、`{大人|おとな}`、`{一人|ひとり}`、`{二十日|はつか}`、`{上手|じょうず}`、`{部屋|へや}`、`{今朝|けさ}`。
- 數字與量詞一起標，注意音變：`{三百円|さんびゃくえん}`、`{六百|ろっぴゃく}`、`{八千|はっせん}`、`{一本|いっぽん}`、`{三階|さんがい}`、`{十分|じゅっぷん}`（時間）、`{四時|よじ}`、`{九時|くじ}`、`{七月|しちがつ}`、`{一日|ついたち}`（日期）／`{一日|いちにち}`（一天）、`{十四日|じゅうよっか}`、`{二十歳|はたち}`、`{何人|なんにん}`、`{一か月|いっかげつ}`。
- 依**上下文**決定讀音：`{行|い}った`／`{行|おこな}った`、`{辛|から}い`／`{辛|つら}い`、`{方|ほう}`／`{方|かた}`、`{家|いえ}`／`{家|うち}`、`{開|あ}く`／`{開|ひら}く`、`{人気|にんき}`、`{後|あと}`／`{後|うし}ろ`、`{間|あいだ}`／`{間|ま}に{合|あ}う`、`{私|わたし}`、`{明日|あした}`、`{何|なに}`／`{何|なん}`、`{止|と}める`／`{止|や}める`、`{入|はい}る`／`{入|い}れる`、`{他|ほか}`、`{中|なか}`／`{一日中|いちにちじゅう}`／`{今週中|こんしゅうちゅう}`。
- 讀音一律用**平假名**（原文是片假名詞就不用標）。`々` 跟著前一個字一起標：`{時々|ときどき}`、`{人々|ひとびと}`。
- 人名地名也要標：`{田中|たなか}`、`{鈴木|すずき}`、`{東京|とうきょう}`。
- 英數字、假名、標點、【】（　）＿＿★ 等符號原樣保留。

## 各欄位

| 欄位 | 內容 | 要求 |
|---|---|---|
| `p` | 題幹 | 所有漢字都要標。**例外：`漢字讀音` 題（檔名含 kanji、或 knowledge.js 中 id 為 kanji-NN）的【】內是考點，【】內不可標註**，【】外照常標。 |
| `o` | 選項 | 所有漢字都要標；純假名選項原樣保留。 |
| `t` | 讀解／文章文法本文、筆記標題 | 所有漢字都要標。 |
| `sc` `qn` `s` | 聽解的場面、提問、台詞 | 所有漢字都要標。 |
| `e` `ie` | 筆記例句 | 所有漢字都要標。 |
| `x` | 繁體中文解析 | **只標註「」內引用的日文詞句**；中文說明文字不要標。引用後面已經用（）寫出讀音的，例如「激しい（はげしい）」，不用再標。「」內若是中文（例如中文翻譯）不要標。拿不準是不是日文就不要標。 |

## 作法

直接編輯指定的 `dist/ruby/<檔名>.js`（已經放好原文），逐條加上標記。檔案很大時分批編輯。不要寫輔助程式去自動產生讀音，請自己逐句判斷。

在 `n3-sprint/` 下執行檢查，直到顯示 OK：

```sh
node tools/furigana.mjs check ruby/<檔名>.js
```

常見錯誤訊息：`text differs from source`＝不小心改到原文（照訊息附近的字去找）；`kanji without furigana`＝漏標；`is not kana`＝讀音裡混了漢字或符號。
通過後請自己再通讀一遍，專門檢查讀音對不對（數字量詞、多音字、送假名的切分）。
