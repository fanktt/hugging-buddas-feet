# 臨時抱佛腳｜N3 考前衝刺室

JLPT N3 的考前刷題網站。純靜態、無後端、無 build，進度存在瀏覽器裡。

**線上版：<https://fanktt.github.io/hugging-buddas-feet/>**

## 功能

- **今日衝刺**：一鍵開始，依序出「到期複習 → 弱點題型新題 → 其他新題」，同一篇文章的題目整組出現。
- **間隔複習**：答錯隔天再出，答對逐級拉長間隔，但不超過距考試天數的一半；作答後可標記「我是猜的」。
- **四科題庫**：文字詞彙、文法、讀解、聽解，共 1,516 題，涵蓋 N3 正式考試的 17 種題型。
- **聽解**：由瀏覽器語音合成朗讀，作答後顯示文字稿；沒有日語語音時改為閱讀文字稿作答。
- **模擬考**：迷你版約 25 分鐘；完整版依 N3 三節 140 分鐘計時，交卷後有 180 分制粗估與逐題檢討。
- **佛腳筆記**：文法句型 140 則、易混淆詞 60 則，可搜尋，有閃卡模式。
- **假名注音**：所有漢字上方顯示假名，可隨時開關；「漢字讀音」題要考的詞不加注音。
- **錯題本**、分科／題型特訓、進度匯出匯入、鍵盤操作（1–4 選答、Enter 下一題）。

## 在本機使用

不需要安裝任何東西，直接用瀏覽器開啟：

```sh
open n3-sprint/dist/index.html
```

## 技術

原生 HTML、CSS、JavaScript，沒有框架、打包工具或相依套件。開站只載入 App 與一份小索引（`manifest.js`）；題庫與注音是 JS 檔，用到哪些題目才以動態 `<script>` 載入對應的檔（所以直接開 `file://` 也能用）。進度存在瀏覽器的 `localStorage`，沒有帳號也沒有伺服器。

## 專案結構

```
n3-sprint/
  dist/            發佈的網站（就是線上看到的全部內容）
    manifest.js    題庫索引（由 tools/manifest.mjs 產生）
    data/          題庫與筆記，一個檔案一種題型，按需載入
    ruby/          假名注音，與題庫檔一一對應，按需載入
  tools/           維護工具與規範（不會發佈）
.github/workflows/ 推上 main 後自動發佈到 GitHub Pages
```

## 維護

需要 Node.js（僅用內建模組，無相依套件）。在 `n3-sprint/` 下執行：

```sh
node tools/manifest.mjs          # 重產題庫索引（新增或修改題庫、注音檔後）
node tools/validate.mjs          # 題庫格式、重複、解析寫法、索引是否最新
node tools/furigana.mjs check    # 注音與原文逐字比對、漏標
node tools/smoke.mjs             # App 冒煙測試（含按需載入）
```

新增或修改題目請先讀 [`n3-sprint/tools/AUTHORING.md`](n3-sprint/tools/AUTHORING.md)，注音請讀 [`n3-sprint/tools/FURIGANA.md`](n3-sprint/tools/FURIGANA.md)。

## 發佈

推上 `main` 且變更到 `n3-sprint/dist/` 時，GitHub Actions 會把 `dist/` 原樣發佈到 GitHub Pages，約一分鐘後生效。

## 關於題庫內容

- 題目、文章、解析與注音皆為 AI 生成的原創練習內容，依 JLPT 公布的 N3 題型編寫，**不是官方試題**，也未經日語教師人工審訂。
- 每題都經過另一個沒看過答案的 AI 盲測作答，用來找出有歧義的題目；注音經程式逐字比對原文，並全數由另一個 AI 逐句校對過讀音。仍可能有疏漏，發現錯誤歡迎回報。
- 模擬考的 180 分換算是按正確率線性估算，僅供參考，不等於正式的尺度得分。
- 聽解音檔來自各裝置內建的語音合成，音質與語調因瀏覽器而異。
